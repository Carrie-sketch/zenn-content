# SafeLine WAF の管理画面にログインできないとき：Docker 上で admin アカウントを再設定する運用メモ

SafeLine は、Web アプリケーションの手前に配置する WAF です。リバースプロキシとして動作し、クライアントからの HTTP トラフィックを検査して、SQL インジェクションや XSS、コマンドインジェクション、SSRF、パストラバーサル、総当たり、HTTP フラッドなどの攻撃を遮断します。Docker と Docker Compose で構築でき、管理コンソールは既定で 9443 番ポートを待ち受けます。SafeLine はクライアントと保護対象サーバーの間に挟まる形で動くため、管理コンソールにログインできないと運用確認や設定変更が滞ります。ただ、今回の復旧手順は再インストール不要で、Docker ホストに接続できれば数分で完了します。

運用していてよく困るのが、管理コンソールの admin パスワードを失念するケースです。初期構築直後に初回パスワードがわからない場合も同様です。この記事では、再インストールせずに管理用アカウントを復旧する手順を、実際の確認コマンドと失敗例を交えて整理します。

まず前提として、復旧作業は Web コンソールからではなく、SafeLine を動かしている Docker ホスト上で実行します。コンソールにアクセスできなくても問題ありません。管理コンソールを提供するコンテナの名前は safeline-mgt です。

## 事前チェック

リセットの前に、次の点を確認しておくと作業がスムーズです。

1. Docker が使えること。`docker version` または `docker ps` を実行し、エラーが出ないことを確認します。
2. 対象コンテナが存在すること。`docker ps --filter name=safeline-mgt` で、safeline-mgt が一覧に表示されることを確認します。停止中のコンテナも含めて探す場合は `docker ps -a` を使います。
3. 管理ポートの設定。インストール時に MGT_PORT を変更した場合は、その値を控えておきます。`.env` ファイルがあれば `grep MGT_PORT .env` で確認できます。
4. 待受ポートの確認。変更していなければ、ホストで `ss -lntp | grep 9443` などを使い、9443 番ポートが待ち受けていることを確認します。ポートが空いていなければ、ファイアウォールやセキュリティグループ、コンテナの起動状態を先に確認します。

## リセット手順

1. ホストのターミナルを開き、次を実行します。コマンドはコンテナ内部ではなく、ホスト側から実行します。

```bash
docker exec safeline-mgt resetadmin
```

2. コマンドの出力を最後まで読みます。成功時には、初期ユーザー名 admin と生成された初期パスワードが表示され、続けて Done と出力されます。この admin と初期パスワードを、その場で安全な場所に控えます。出力はスクロールで見失いやすいため、端末のバッファを遡って丁寧に確認します。

3. ブラウザで次のアドレスを開きます。

```text
https://<safeline-ip>:9443/
```

`safeline-ip` は SafeLine サーバーの IP アドレスに置き換えます。MGT_PORT をカスタマイズした場合は、9443 の代わりにそのポートを使います。

4. ユーザー名 admin と、手順 2 で控えた初期パスワードでログインします。ログインできれば、管理画面から SafeLine の運用を再開できます。

## 失敗例：コンテナ名の違い

よくあるのが、`docker exec safeline-mgt resetadmin` を実行して「そのようなコンテナはない」というエラーになるケースです。原因の多くは、コンテナ名の先頭にプロジェクト名が付いている、または別のホストで実行していることです。まず `docker ps` で表示名を確認し、実際の名前が safeline-mgt になっているかを確かめます。コンテナが停止している場合は `docker ps -a` も確認します。コンテナが動いていない状態では resetadmin が実行できないため、必要に応じて起動してから再実行します。

## 失敗例：出力の見落とし

もうひとつ多いのが、パスワードの見落としです。出力は長くないものの、初期パスワードが表示された直後に Done が出るため、慌てて端末を閉じると控え損ねます。まずは出力全体を確認し、admin と初期パスワードの両方を記録してからブラウザへ進みます。

## 運用のヒント

このコマンドは公式ドキュメントの導入ガイドで「管理者アカウントの取得」として案内されている手順です。新規インストール直後の初回ログインにも使えます。出力された初期パスワードは安全な場所に保管し、画面共有やチャットへそのまま貼り付けることは避けます。リセットは本当に必要なときだけ実行し、むやみに再実行しないようにします。管理コンソールは `https://<safeline-ip>:9443/` です。詳細は公式ドキュメント（https://docs.waf.chaitin.com/en/home）を参照してください。
