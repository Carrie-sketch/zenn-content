ブロックページがでたとき、まずわかるのは「そのリクエストがとめられた」ということです。それだけで、あくいのあるアクセスだったとはいいきれません。ふだんのフォームそうしんだったのか、きょかされたテストだったのかを、ブラウザーでのそうさと SafeLine のきろくをつきあわせてたしかめます。

このガイドでは、ブロックのあとにどこをひらき、なにをひかえ、どのタイミングでせっていをみなおすかを、うんようのながれにそってまとめます。

## 1. ブロックされたときのじょうきょうをひかえる

ページをとじるまえに、おおよそのじこく、アクセスしたホスト、パス、ちょくぜんのそうさをメモします。たとえば「14:20 ごろ、portal.example の /profile でフォームをそうしんしたらブロックされた」というかたちです。

URL をひらいただけなのか、ボタンをおしたのか、フォームをそうしんしたのかもわけてかきます。おなじパスへのアクセスでも、そうさのちがいがきろくをたどるてがかりになります。

ただし、パスワード、セッション Cookie、フォームにいれたひみつのデータは、きょうゆうチケットへそのままはりつけないでください。メモのもくてきは、リクエストをたどるためのじょうきょうをのこすことです。

## 2. SafeLine のコンソールへサインインする

ブラウザーで `https://<ip>:9443` をひらきます。`<ip>` は SafeLine サーバーの IP アドレスにおきかえてください。すでにつかえるアカウントがあれば、そのアカウントでサインインします。

あたらしくセットアップしたかんきょうで、さいしょのかんりしゃアクセスをよういするときは、こうしきのてじゅんにあるつぎのコマンドをつかいます。

```bash
docker exec safeline-mgt resetadmin
```

コマンドがかえしたかんりしゃのじょうほうでサインインします。すでにログインできるなら、ブロックをしらべるためだけにこのコマンドをうごかすひつようはありません。

## 3. ブラウザーからアプリまでのけいろをたしかめる

こうげきのきろくをさがすまえに、ブラウザーがどのホストへアクセスしたかをたしかめます。ブックマークやリンクからひらいたときも、アドレスバーのホストをみてください。

SafeLine は HTTP/HTTPS のリバースプロキシとしてリクエストをうけ、フィルタリングし、とおしてよいものをアップストリームのアプリへわたします。そのため、しらべたいアプリへのアクセスが SafeLine をとおるせっていになっているかがたいせつです。

コンソールの `Applications` で、アプリのドメイン、SafeLine がまちうけるポート、アップストリームのアドレスをたしかめます。HTTPS のアプリでは SSL のせっていもみます。DNS のむきさきが SafeLine サーバーの IP アドレスになっているかもチェックしてください。

あたらしくアプリをとうろくするばあいのいりぐちは `Applications` → `Add Application` です。すでにあるアプリをしらべるときは、まずそのせっていとブラウザーのアクセスさきをつきあわせます。

## 4. こうげきリストから `detail` をひらく

コンソールでこうげきリストをひらきます。ひかえたじこく、ホスト、パスなどのじょうきょうと、がめんにでているじょうほうをつきあわせ、あてはまるきろくをさがします。そのきろくの `detail` をクリックすると、くわしいないようへすすめます。

ここでたいせつなのは、じっさいのがめんにあるじょうほうをこんきょにすることです。こうしきのアプリせっていガイドは、このリストから `detail` へすすむながれをしめしていますが、そこでみられるすべてのこうもくまではれっきょしていません。

ブロックページにでた ID でけんさくできる、ペイロードのせんようこうもくがある、エクスポートできる、といったきのうをまえもってあてにしないでください。まずは、リストと `detail` でたしかめられるきろくをよみます。

## 5. そうさときろくがつながるかをたしかめる

ひらいたきろくが、メモしたブラウザーのそうさにあてはまるかをみます。じこくがちかいというりゆうだけで、すぐにおなじリクエストだときめつけないようにします。がめんでたしかめられるじょうほうをつかい、ホストやパスなどもつきあわせてください。

そのうえで、きょかされたセキュリティテストなのか、おぼえのないアクセスなのか、ふだんのアプリそうさがとめられたのかをせいりします。テストをやりなおすなら、じぶんがもつアプリ、またはテストのきょかをえたアプリだけをつかいます。

つながりをたしかめられないときは、アプリのせってい、DNS、アップストリーム、ブラウザーのホストへもどってチェックします。ブロックページをけすことだけをもくてきに、ぼうぎょのせっていをかえるのはさけましょう。

## 6. みじかいしっぱいれい：じこくだけでえらんでしまう

フォームをそうしんしてブロックされたため、たんとうしゃがすぐにこうげきリストをひらき、いちばんあたらしいきろくをえらびました。しかし、べつのテストもおなじころにおこなわれており、そのきろくをフォームのブロックとむすびつけるこんきょがたりませんでした。

このばあいは、せっていをかえるまえに、フォームをつかったじこく、ホスト、パス、そうさをメモしなおします。つぎに `detail` のないようとつきあわせ、わかったことと、まだわからないことをチケットへわけてのこします。

ブロックのきろくとユーザーのそうさがつながってから、アプリがきたいするうごきと、じっさいにとまったリクエストをもとに、せっていのみなおしがひつようかをはんだんしてください。
